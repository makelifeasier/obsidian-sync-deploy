# Gemini Helper 共享检索

1. 确认用户同意将审核范围内的数据交给 Gemini API，检查项目计费状态、地区可用性、模型、额度和当前免费数据条款。Gemini 消费者订阅与 Gemini API 计费分开。先用合成请求实测免费模型及 File Search，额度错误时报告原因，不自动切付费项目。
2. Windows 负责建立和增量刷新索引。从审核通过的精确文件路径生成白名单。排除敏感资料、设备配置、问答输出以及未经审核的附件。新增文件先审核再入白名单。预览拟上传清单，空文件不索引。验证源文件删除能移除相关索引文档。
3. 三端密钥通过设备的 Obsidian SecretStorage 保存。用重开应用后的 API 成功请求验证持久性。若安卓显示输入完整却返回 401，先确认保存的值是否截断，再判断项目权限、模型和网络。可私下比较完整值，报告只记录是否一致及 HTTP 状态。
4. 移动端连接同一 File Search store，使用 External 模式，先核对确实为外部存储，避免手机重复上传。设置 Vault 工具默认关闭、网页搜索关闭以及默认引用规则。让模型按检索内容回答，给可定位笔记来源，资料不足时明确说明。整理内容保留在聊天预览，由用户另存到指定输出目录。
5. 每端问一个有已知来源的问题和一个不存在的合成问题。验证引用能打开正确笔记，缺失资料不编造。用合成文档测试索引修改和删除。正式索引变化用校验值或索引状态验证。文件同步与索引刷新分开，日常更新在电脑操作。
